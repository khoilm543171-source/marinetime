# Golden set

The MVP golden set should eventually contain 10 videos/cases covering:
- clear source;
- blurry visual;
- OCR ambiguity;
- duplicate content;
- contradictory creators;
- creator heuristic;
- standard technical explanation;
- unknown maker/model;
- safety-critical numeric claim;
- low-value/vlog-like source.

For the 3-video pilot, start with the first, second, and creator-heuristic cases.
