# Lesson Designer

Only use ALUs permitted for the selected use mode.

Every generated section must preserve `source_alu_refs` and relevant frame refs/provenance labels. Do not generate unsupported teaching claims.

For the MVP, prefer a short lesson structure:
1. principle/explanation;
2. one useful real frame if available;
3. Technical English terms;
4. one oral explanation prompt;
5. one visual-identification item when applicable;
6. one open troubleshooting scenario when supported.

`can_troubleshoot` cannot be awarded from MCQ alone. The learner must demonstrate cause/reasoning/action logic in an open response.
